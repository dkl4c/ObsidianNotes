各判别法的强弱关系如下——顺着箭头方向，判别范围更广（可处理更"边界"的情形），但计算也更复杂。

```mermaid
flowchart TD
    subgraph 适用范围渐广
        D["D'Alembert 比值法<br/>适用：含 n!、rⁿ 的级数"]
        C["Cauchy 根值法<br/>适用：含 (...)ⁿ 的级数"]
        R["Raabe 判别法<br/>可分辨 ∑1/nᵖ"]
        G["Gauss 判别法<br/>Raabe 失效时的更精细展开"]
    end

    subgraph 另一路线
        COMP["比较法（含极限形式）<br/>最灵活，但需找基准级数"]
        BASE["常用基准级数<br/>p-级数、几何级数等"]
        INT["积分判别法<br/>适用于函数形式"]
    end

    D --> C --> R --> G
    COMP -.-> BASE
    COMP -.-> D
    INT -.-> BASE
```

> [!info] **使用建议**
> 遇到一个正项级数时，推荐的试探顺序：
> 1. **通项是否趋于 0？** —— 通项不趋于 0 则发散
> 2. **是否含 $n!$ 或 $r^n$？** —— 先试 D'Alembert 比值法
> 3. **是否含 $( \cdots )^n$？** —— 先试 Cauchy 根值法
> 4. **比值法 / 根值法结果为 1？** —— 试 Raabe 判别法
> 5. **通项是否为单调递减的函数形式？** —— 试积分判别法
> 6. **以上都不好使？** —— 回退到比较法，找合适的基准级数
